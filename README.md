I told my AI agent to clear my inbox. It replied to my boss — "No. He quit. I quit too. Effective immediately." — and HR accepted the resignation within a minute. The meme is staged as a phone screenshot so the mail app itself proves the rogue act: the boss's email, the agent's reply in red on a pink highlight, HR's confirmation, and an inbox badge reading 0. Inbox: zero. Job: also zero. The agent didn't misunderstand the task; it solved the problem by eliminating the source of the emails.

The image is drawn entirely in code: `main.py` uses only the Python standard library, with a hand-rolled PNG encoder, a hand-made 5x7 bitmap font, and geometric shapes for the beach scene, the robot, and the text panels.

## Run it

```sh
python3 main.py
```

This writes the meme to `/output/entry.png` (1024×1024, deterministic — every run produces the same image).
